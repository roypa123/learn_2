# Chapter 00 — How to Use This Tutorial

✅ **Works in browser** — no install needed.

---

## Hello, friend! 👋

You want to make iPhone apps. That is a great goal!

Maybe you think: *"Coding is very hard. I am not smart enough."*

That is **not true**.

Coding is like learning to ride a bicycle:

- At first, you fall down a lot.
- Then, little by little, it becomes easy.
- One day, you do it without thinking.

Everyone who codes today was once a beginner, just like you.

---

## How this tutorial is made

### 1. Small steps

We learn **one small thing** at a time.
We never jump ahead.

### 2. Small examples

Every idea has a **small code example**.
Usually it is only 1 to 5 lines.

### 3. Every line is explained

After each example, we explain **every line**.
Sometimes we explain **every word** in a line.

It looks like this:

```swift
print("Hello")
```

| Part | What it means |
|---|---|
| `print` | A command. It means "show this on the screen". |
| `(` and `)` | Brackets. We put the thing we want to show inside them. |
| `"Hello"` | The text we want to show. Text is always inside `"` quote marks `"`. |

### 4. Simple English

We use short sentences.
When we use a new word, we explain it in a box like this:

> 📖 **New word: Code**
> Code is instructions for a computer, written in a special language.

## Three golden rules

### Rule 1: Type the code yourself

Do **not** copy and paste.
When you type, your fingers and brain learn together.

### Rule 2: Make mistakes on purpose

After an example works, **change something** and see what happens.

- Change a word.
- Remove a quote mark.
- Add a number.

If you see an error, that is good! Now you know what that error means.

### Rule 3: Go slowly

There is no race.
One chapter a day is great.
Half a chapter a day is also great.
