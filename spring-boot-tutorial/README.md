# Spring Boot for Complete Beginners

Welcome! 👋

This book teaches you **Java** and **Spring Boot** from zero.

- You do **not** need to know any programming.
- You do **not** need to speak perfect English. We use short sentences and easy words.
- Every piece of code is explained **line by line**.
- Every chapter has **small examples**, a **summary**, and a **small quiz**.

---

## How to use this book

1. Read the chapters **in order**. Each chapter uses what you learned before.
2. **Type the code yourself.** Do not copy and paste. Typing helps your brain remember.
3. If something does not work, read the **"Common mistakes"** part of the chapter.
4. Do the **quiz** at the end of each chapter. The answers are below the questions.
5. Go slowly. One chapter per day is very good.

> 💡 **Emojis look strange?** Some examples print emojis like ✅ or 🎉. In IntelliJ they usually look fine. In the Windows terminal they may show as `?` or strange symbols. That is only a display problem, and the program is still correct. To fix it in the terminal, run with `java -Dstdout.encoding=UTF-8 YourProgram.java`.
