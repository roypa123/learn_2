# Grammar Combination Matrix

Real sentences use **many grammar rules at the same time**. This file lists the combinations the course will teach.

A combination is taught **only after every part has been taught alone**. The "Needs" column shows those lessons.

Status: ⬜ not started · 🟡 in progress · ✅ complete (target examples + exercises + answers + revision done).
Target examples: 100 for every combination unless marked.

---

## How every combination file is taught (20 steps)

1. Explain each rule alone (short reminder + link).
2. Why these rules are joined.
3. The sentence pattern.
4. Where each part goes.
5. Subject–verb agreement.
6. Tense and verb-form choices.
7. Meaning of the whole sentence.
8. Punctuation.
9. Basic examples.
10. Intermediate examples.
11. Advanced examples.
12. Common learner mistakes.
13. When **not** to use this combination.
14. Natural vs unnatural alternatives.
15. Spoken and written examples.
16. Positive, negative, questions, different times.
17. Long examples with earlier topics.
18. Practice exercises.
19. Answers with explanations.
20. Revision plan.
