## Part A — Prerequisite map (what comes before what)

```
Language → Letters → Sounds → Words → Word meanings (things / actions / describing)
   → Sentence idea → Subject + Verb → Word order (S-V-O)
   → Word classes (noun, pronoun, verb, adjective, article…)
   → "be" sentences → present simple → present continuous
   → past simple → future forms → perfect tenses → continuous perfect tenses
   → modals (simple) → modals (perfect)
   → simple sentence → compound sentence (and/but/so)
   → complex sentence (because/when/if) → compound-complex sentence
   → clauses (noun / relative / adverb) → reduced clauses, participle clauses
   → passive voice (needs: be + past participle + tenses)
   → reported speech (needs: tenses + pronouns + noun clauses)
   → conditionals 0/1 (needs: present + will) → 2 (needs: past) → 3 (needs: past perfect) → mixed
   → grammar combinations (2 rules → 3 rules → many rules)
   → natural speech, register, style, advanced writing
```

Key dependencies explained:

- **Verbs before tenses.** You must know what a verb is before you can change its time.
- **"be" before continuous and passive.** "She *is* reading" and "It *was* made" both use "be" as a helper.
- **Past participles before perfect tenses and passive.** "have *eaten*", "was *eaten*" use the same verb form.
- **Simple sentences before joined sentences.** You must build one clause before joining two.
- **Tenses before reported speech and conditionals.** These topics *change* tenses, so you must know the tenses first.
- **Each single topic before its combinations.** "Neither…nor + subject–verb agreement" needs both parts first.
